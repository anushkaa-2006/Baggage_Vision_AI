# 🧳 Baggage Vision AI
### AI-Powered X-Ray Baggage Screening System

Baggage Vision AI is an AI-based baggage screening assistance system designed to analyze X-ray images and help identify potentially prohibited objects and unusual baggage contents. It combines deep learning-based object detection with anomaly detection to generate a risk assessment for human review.

The system is intended to support baggage screening workflows in airports, metro stations, and railway stations.

> **Disclaimer:** This project is a prototype for screening assistance and research. Its predictions are not definitive security clearances. All flagged images and screening decisions must be reviewed by a qualified human operator.

## ✨ Features

- **X-ray Image Preprocessing:** Enhances image contrast using CLAHE and other configured preprocessing operations.
- **Object Detection:** Uses a trained YOLOv8x model to identify objects belonging to its trained classes, such as guns and knives.
- **Anomaly Detection:** Extracts image features using ResNet50 and compares them against reference features using a k-nearest-neighbor (k-NN) approach.
- **Risk Assessment:** Combines detection and anomaly scores to estimate the risk level.
- **Visual Results:** Displays the analyzed X-ray image, detected objects, bounding boxes, confidence scores, and risk decision.
- **Interactive Dashboard:** Provides a Streamlit-based user interface for uploading and analyzing images.

## 🏗️ System Architecture

The system follows this pipeline:

1. **Input:** The user uploads an X-ray baggage image in PNG, JPG, or JPEG format.
2. **Preprocessing:** The image is enhanced using the configured image preprocessing pipeline.
3. **Object Detection:** YOLOv8x detects recognizable objects and returns their labels, locations, and confidence scores.
4. **Anomaly Detection:** ResNet50 extracts features, which are compared with stored normal reference features to calculate an anomaly score.
5. **Risk Mapping:** Detection and anomaly scores are combined to estimate the overall risk.
6. **Results:** Streamlit displays the annotated image, detected objects, scores, and risk decision.

## 🧠 Risk Assessment

The pipeline calculates the following scores:

- **Detection Score:** A score derived from the object detection stage.
- **Anomaly Score:** Estimates how different the image features are from the stored normal reference features.
- **Mismatch Score:** Currently set to `0.0` in the baggage screening pipeline.
- **Risk Score:** A combined score calculated by the project's risk mapping logic.

The final decision is generated by the configured risk mapping module. Depending on the thresholds defined in the implementation, the result may be categorized as:

- **SAFE**
- **SUSPICIOUS**
- **HIGH RISK**

These labels are preliminary model outputs, not guarantees that baggage is safe or unsafe.

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/anushkaa-2006/Baggage_Vision_AI.git
cd Baggage_Vision_AI
```

### 2. Create a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks environment activation, you can run the environment's Python and pip executables directly.

### 3. Install dependencies

If `requirements.txt` is included:

```powershell
python -m pip install -r requirements.txt
```

Make sure your PyTorch and other dependencies are compatible with your system.

### 4. Add the trained model

The trained model weights are not included in this repository because `best.pt` is larger than GitHub's standard 100 MB individual-file limit.

Obtain `best.pt` from the project maintainer or your authorized model storage and place it at:

```text
frontend/models/best.pt
```

The model file must match the model architecture and classes expected by the detection code.

### 5. Verify the anomaly reference features

Make sure the reference feature file is available at:

```text
frontend/anomaly_detection/normal_features.npy
```

This file is required by the anomaly detection component. If it is not distributed with the repository, obtain it from the project maintainer or generate it using the project's feature extraction workflow and appropriate normal reference images.

## ▶️ Run the Application

From the project root directory, run:

```powershell
python -m streamlit run frontend/app.py
```

Streamlit will provide a local URL in the terminal. Open that URL in your browser to use the application.

### Using the Dashboard

1. Upload an X-ray baggage image.
2. Click **Analyze X-ray**.
3. Wait for preprocessing, object detection, and anomaly scoring to finish.
4. Review the annotated X-ray image and detected-object table.
5. Examine the detection, anomaly, and risk scores.
6. Review any flagged baggage with a qualified human operator.
